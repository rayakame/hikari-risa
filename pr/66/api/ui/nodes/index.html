risa.ui.nodes¶

The components a view's layout is built from, Discord's Components V2.

A layout is one top-level component or a sequence of them. Interactive components take the handler a click routes to, bare as self.save or with wire arguments as risa.bind(self.vote, 2). risa checks only what Discord cannot: that each custom_id fits, and that each handler belongs to the view. Discord's own limits, such as five buttons to a row, are left to Discord.

ContainerChild ¶

ContainerChild = File | MediaGallery | Row | Section | Separator | TextDisplay

A component that fits in a Container.

Layout ¶

Layout = TopLevelComponent | Sequence[TopLevelComponent]

What View.render returns: one top-level component, or several in order.

A component that can stand at the top of a message.
