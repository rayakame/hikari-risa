Dependency injection¶

A handler often needs something from outside its view, such as your database. Register it once at startup, name it as a parameter, and risa passes it in on every click.

Why you need it¶

This shop shows a price when someone clicks an item. The prices are in your database, so the handler that answers the click needs your database.

A function of your own gets what it needs as arguments, because you write the call. You never call a handler: a click comes in, and risa calls it. The view can't hold your database either, because its fields get saved from click to click, and @risa.register raises ViewDeclarationError on a type it can't save.

So the handler names what it needs as a parameter, and risa passes it in. Your database is a dependency of the handler, and passing it in is injecting it.

  1. 1You register itAt startup, you tell risa which object a Prices parameter gets.
  2. 2The handler names itIt takes a parameter, prices: Prices.
  3. 3risa passes it inOn each click, risa calls the handler with that object.

A global variable would do for a small object like this one. A connection pool opens only once the bot is running, so its global would stay empty until then, and each handler would have to check it.

Register it¶

Prices is your own class, standing in for your database, and you can find it in the full file. main() calls this once, before the bot starts.

def add_dependencies(client: risa.Client) -> None:
    registry = client.di.registry_for(risa.Contexts.DEFAULT)
    registry.register_value(Prices, Prices())

register_value(Prices, Prices()) says that a parameter annotated Prices gets this one object. registry_for picks where it's kept, and risa.Contexts.DEFAULT keeps it for the whole run. client.di is the manager of linkd, the library risa injects with.

Do this before the bot starts: once a click or a view's load() has used the manager, register_value raises linkd's RegistryFrozenException.

A connection pool has to open inside the running event loop, so register a function for it: registry.register_factory(Pool, open_pool, teardown=close_pool) calls open_pool at first use, and await client.di.close() calls the teardown.

Name it as a parameter¶

A click on an item runs show, which names what it needs.

@risa.handler
async def show(
    self,
    ctx: risa.ComponentContext,
    item: str,
    prices: Prices,
    client: risa.Client,
) -> None:
    offer = Offer(item=item, price=await prices.of(item))
    await ctx.respond(**await client.build(offer), ephemeral=True)
Parameter Filled by
ctx risa, by position
item: str The wire argument bound to the button
prices: Prices, client: risa.Client Injection, going by the annotation, so any name will do

risa tells them apart by type. str is a type an argument can have, so item comes from the button. Prices is not, so prices is injected.

Later chapters add load(), on_state_missing and on_outdated, which take injected parameters the same way.

If nothing is registered for a parameter, the handler does not run: risa logs linkd's DependencyNotSatisfiableException, and the click fails in Discord. A handler with only ctx and wire arguments needs nothing from linkd.

Build another view¶

A handler needs the client for client.build, and the client is a local variable of main(). risa registers it, so show above names it, builds an Offer and sends that as its answer. This is the other view, and main() adds both to the client.

@risa.register(name="offer")
class Offer(risa.View):
    item: str
    price: int

    def render(self) -> ui.Layout:
        return ui.Container(
            ui.TextDisplay(f"{self.item.title()}: {self.price} coins"),
            ui.Row(ui.Button(self.buy, label="Buy")),
        )

    @risa.handler
    async def buy(self, ctx: risa.ComponentContext) -> None:
        await ctx.edit(ui.TextDisplay(f"You bought the {self.item}."))

"""A shop whose handler takes a wire argument, your database and the client."""

from __future__ import annotations

import asyncio
import os

import hikari

import risa
from risa import ui

_PRICES = {"apple": 3, "pear": 4}


class Prices:
    async def of(self, item: str) -> int:
        await asyncio.sleep(0.1)
        return _PRICES[item]


@risa.register(name="offer")
class Offer(risa.View):
    item: str
    price: int

    def render(self) -> ui.Layout:
        return ui.Container(
            ui.TextDisplay(f"{self.item.title()}: {self.price} coins"),
            ui.Row(ui.Button(self.buy, label="Buy")),
        )

    @risa.handler
    async def buy(self, ctx: risa.ComponentContext) -> None:
        await ctx.edit(ui.TextDisplay(f"You bought the {self.item}."))


@risa.register(name="shop")
class Shop(risa.View):
    def render(self) -> ui.Layout:
        buttons = [
            ui.Button(
                risa.bind(self.show, item),
                label=item.title(),
            )
            for item in _PRICES
        ]
        return ui.Container(ui.TextDisplay("## Shop"), ui.Row(*buttons))

    @risa.handler
    async def show(
        self,
        ctx: risa.ComponentContext,
        item: str,
        prices: Prices,
        client: risa.Client,
    ) -> None:
        offer = Offer(item=item, price=await prices.of(item))
        await ctx.respond(**await client.build(offer), ephemeral=True)


def add_dependencies(client: risa.Client) -> None:
    registry = client.di.registry_for(risa.Contexts.DEFAULT)
    registry.register_value(Prices, Prices())


def main() -> None:
    bot = hikari.GatewayBot(
        os.environ["DISCORD_TOKEN"],
        intents=hikari.Intents.ALL_UNPRIVILEGED | hikari.Intents.MESSAGE_CONTENT,
    )
    client = risa.client_from_app(bot)
    add_dependencies(client)
    client.add_view(Shop)
    client.add_view(Offer)

    @bot.listen()
    async def on_message(event: hikari.GuildMessageCreateEvent) -> None:
        if event.content == "!shop":
            rendered = await client.build(Shop())
            await rendered.send_to(bot.rest, event.channel_id)

    bot.run()


if __name__ == "__main__":
    main()

What risa registers¶

These need no registering from you:

Parameter What it gets
client: risa.Client The risa client. risa.GatewayEnabledClient is not registered, so annotate it this way
rest: hikari.api.RESTClient The bot's REST client
bot: hikari.GatewayBot, events: hikari.api.EventManager On a gateway bot, the bot and its event manager
bot: hikari.RESTBot, server: hikari.api.InteractionServer On a REST bot, the bot and its interaction server

Share one manager with lightbulb¶

risa.client_from_lightbulb makes a client on lightbulb's manager, so what you register with lightbulb reaches your handlers too. lightbulb registers the hikari types above itself.

registry = lightbulb_client.di.registry_for(lightbulb.di.Contexts.DEFAULT)
registry.register_value(Prices, Prices())
risa_client = risa.client_from_lightbulb(lightbulb_client)
risa_client.add_view(Shop)
lightbulb_client.register(ShopCommand)

A command gets the risa client the same way:

class ShopCommand(
    lightbulb.SlashCommand,
    name="shop",
    description="Open the shop.",
):
    @lightbulb.invoke
    async def invoke(self, ctx: lightbulb.Context, client: risa.Client) -> None:
        await ctx.respond(**await client.build(Shop()))

"""The shop on lightbulb's manager, so one registration reaches both."""

from __future__ import annotations

import asyncio
import os

import hikari
import lightbulb

import risa
from risa import ui

_PRICES = {"apple": 3, "pear": 4}


class Prices:
    async def of(self, item: str) -> int:
        await asyncio.sleep(0.1)
        return _PRICES[item]


@risa.register(name="shop")
class Shop(risa.View):
    def render(self) -> ui.Layout:
        buttons = [
            ui.Button(
                risa.bind(self.show, item),
                label=item.title(),
            )
            for item in _PRICES
        ]
        return ui.Container(ui.TextDisplay("## Shop"), ui.Row(*buttons))

    @risa.handler
    async def show(
        self,
        ctx: risa.ComponentContext,
        item: str,
        prices: Prices,
    ) -> None:
        price = await prices.of(item)
        await ctx.respond(f"{item.title()}: {price} coins", ephemeral=True)


class ShopCommand(
    lightbulb.SlashCommand,
    name="shop",
    description="Open the shop.",
):
    @lightbulb.invoke
    async def invoke(self, ctx: lightbulb.Context, client: risa.Client) -> None:
        await ctx.respond(**await client.build(Shop()))


def main() -> None:
    bot = hikari.GatewayBot(os.environ["DISCORD_TOKEN"])
    lightbulb_client = lightbulb.client_from_app(bot)
    bot.subscribe(hikari.StartingEvent, lightbulb_client.start)

    registry = lightbulb_client.di.registry_for(lightbulb.di.Contexts.DEFAULT)
    registry.register_value(Prices, Prices())
    risa_client = risa.client_from_lightbulb(lightbulb_client)
    risa_client.add_view(Shop)
    lightbulb_client.register(ShopCommand)

    bot.run()


if __name__ == "__main__":
    main()
