risa.client¶

The client that routes clicks to views, and the functions that make one.

Client ¶

Client(
    rest: RESTClient,
    *,
    use_global: bool = False,
    di: DependencyInjectionManager | None = None,
    register_app_dependencies: bool = True,
    auto_defer: AutoDefer = OFF,
    auto_defer_delay: float = AUTO_DEFER_DELAY,
    store: Store | None = None,
    stores: Mapping[str, Store] | None = None,
    key_prefix: str | None = None,
)

Bases: ABC

Routes clicks on registered views to their handlers.

Make one with client_from_app or client_from_lightbulb, add views with add_view, and send a view with build. A client answers only custom_ids risa wrote, so it can share a bot with other component handlers.

Parameters:

  • rest (RESTClient) –

    The REST client risa answers interactions through.

  • use_global (bool, default: False ) –

    Also route views registered with @risa.register but never added to this client.

  • di (DependencyInjectionManager | None, default: None ) –

    The linkd manager handlers are injected from; a new one by default.

  • register_app_dependencies (bool, default: True ) –

    Register the app, its REST client, and its event manager or interaction server for injection.

  • auto_defer (AutoDefer, default: OFF ) –

    The AutoDefer of views and handlers that set none, OFF by default.

  • auto_defer_delay (float, default: AUTO_DEFER_DELAY ) –

    Seconds after which auto-defer answers a click in its handler's place.

  • store (Store | None, default: None ) –

    The store InStore views use unless they name another.

  • stores (Mapping[str, Store] | None, default: None ) –

    Further stores, by the name InStore(store=...) refers to them by.

  • key_prefix (str | None, default: None ) –

    The prefix of every store key, risa:{application id} by default. Set it to fit a Redis ACL pattern, or to separate bots that share one store.

Raises:

  • ValueError –

    If key_prefix is blank, or the default store is given both as store and in stores.

Route clicks on the components of cls through this client.

Parameters:

Returns:

  • type[T] –

    The class, so that this also works as a decorator above @risa.register.

build async ¶

build(view: View) -> Rendered

Render view into the components of a new message, ready to send.

await ctx.respond(**await client.build(Poll(question="Ship it?")))

It runs the view's load, renders it, and writes an InStore view's first record. The result spreads into any hikari or lightbulb call that takes components=. If that send fails, the record stays behind until its TTL reaps it, or for good under InStore(ttl=None).

Parameters:

  • view (View) –

    The view to render, an instance of a registered class.

Returns:

  • Rendered –

    The components, as a mapping that spreads into a send.

Raises:

  • NotAViewError –

    If the view's class was never registered.

  • ViewDeclarationError –

    If the view keeps its state in a store this client does not have.

  • StateOverflowError –

    If an InMessage view's state does not fit its components.

RestEnabledClient ¶

RestEnabledClient(
    app: RestClientAppT,
    *,
    register_app_dependencies: bool = True,
    warn_shared_listener: bool = True,
    **options: Unpack[_ClientOptions],
)

Bases: Client

A client that receives clicks from hikari's interaction server.

The interaction server has a single component listener. The client takes it over and passes every interaction it does not handle on to the listener it replaced, and it logs a warning naming that listener unless warn_shared_listener=False. client_from_app or client_from_lightbulb makes one.

app: RestClientAppT

client_from_app(
    app: RestClientAppT,
    *,
    warn_shared_listener: bool = True,
    **options: Unpack[_ClientOptions],
) -> RestEnabledClient

Make a client for a hikari app, gateway or REST.

bot = hikari.GatewayBot(TOKEN)
client = risa.client_from_app(bot, store=risa.MemoryStore())

Parameters:

  • app (GatewayClientAppT | RestClientAppT) –

    The app to receive interactions from.

  • warn_shared_listener (bool, default: True ) –

    REST only: warn when the client takes over a component listener another library set.

  • **options (Unpack[_ClientOptions], default: {} ) –

    The options of Client.

Returns:

  • Client –

    A GatewayEnabledClient or a RestEnabledClient, depending on the app.

client_from_lightbulb ¶

client_from_lightbulb(
    lightbulb_client: LightbulbClient,
    *,
    warn_shared_listener: bool = True,
    **options: Unpack[_LightbulbOptions],
) -> Client

Make a client that shares a lightbulb client's app and dependency manager.

Handlers can then be injected with anything registered with lightbulb. The app's own dependencies are left to lightbulb, which registers them already.

Parameters:

  • lightbulb_client (LightbulbClient) –

    The lightbulb client to share.

  • warn_shared_listener (bool, default: True ) –

    REST only: warn when the client takes over lightbulb's component listener.

  • **options (Unpack[_LightbulbOptions], default: {} ) –

    The options of Client, apart from di.

Returns:

  • Client –

    A GatewayEnabledClient or a RestEnabledClient, depending on the app.

Raises:

  • TypeError –

    If the lightbulb client's app is neither a gateway nor a REST app.
