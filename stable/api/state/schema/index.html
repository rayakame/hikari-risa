risa.state.schema¶

A view's durable fields, and how their values are packed into state.

Fields are durable by default. risa.Prop[T] marks a field that is rebuilt fresh on every click instead: it is never saved, costs nothing on the wire, must have a default, and is typically filled in load.

Prop ¶

Prop = Annotated[T, _PropMarker]

Marks a view field as a per-dispatch prop: refilled in load() and never written to state.

DurableField ¶

DurableField(name: str, annotation: object, has_default: bool)

Bases: Struct

One durable field of a view.

Attributes:

  • name (str) –

    The field's name.

  • annotation (object) –

    The field's type.

  • has_default (bool) –

    Whether the field has a default, which lets state written before it was added still be read.

StateSchema ¶

StateSchema(fields: Sequence[DurableField], *, view_name: str)

The durable fields of a view, in declaration order, and their packing.

risa builds one per view at registration. State is packed as the values of the durable fields in order, so appending a field that has a default leaves earlier state readable.

durable property ¶

durable: bool

Whether the view has any durable fields.

empty_fingerprint property ¶

empty_fingerprint: str

The fingerprint of a view without durable fields.

fields property ¶

fields: Sequence[DurableField]

The durable fields, in declaration order.

fingerprint property ¶

fingerprint: str

The hash of the durable fields' names and types, which state is tagged with.

unpack ¶

unpack(fingerprint: str, raw: bytes) -> Sequence[object] | None

Unpack state tagged fingerprint, or return None if this schema cannot read it.

Parameters:

  • fingerprint (str) –

    The fingerprint the state was tagged with when it was saved.

  • raw (bytes) –

    The packed bytes saved under that fingerprint.

Returns:

  • Sequence[object] | None –

    The values of the durable fields, or None if this schema cannot read the state. State saved before a field was added holds only the fields it had, so the sequence stops short of those added since.

Returns:

  • Sequence[object] –

    The values, one per durable field.

structural_type_id ¶

structural_type_id(annotation: object) -> str

Describe a field type by its structure, for the schema fingerprint.

An enum or Literal counts by the kinds of its values, so a new value of a kind it already has leaves old state readable, and a removed one fails only for the state that holds it. A Literal that gains a kind, or loses its last value of one, changes the shape.

Parameters:

  • annotation (object) –

    The field's type annotation.

Returns:

  • str –

    The same text for types of the same structure, whatever they are named.

Raises:

  • ValueError –

    If msgspec cannot describe the type.
