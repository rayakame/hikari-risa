risa.state¶

Where a view's state lives, and which of its fields are state.

DEFAULT_STORE module-attribute ¶

DEFAULT_STORE = 'default'

The name of the client's store=, for InStore(store=...).

DEFAULT_PLACEMENT module-attribute ¶

DEFAULT_PLACEMENT = InMessage()

The placement of a view that declares none: InMessage with the default codec.

StatePlacement ¶

StatePlacement = InMessage | InStore

Either placement a view can declare as its state=.

Prop ¶

Prop = Annotated[T, _PropMarker]

Marks a view field as a per-dispatch prop: refilled in load() and never written to state.

InMessage ¶

Bases: Struct

Keep a view's durable state inside the message it renders.

The default placement. The state is written into the spare characters of the rendered components' custom_ids and read back from the message on every click. It needs no infrastructure, survives restarts, and lives exactly as long as the message. It is bounded by what the components can carry: up to about 70 bytes per interactive component with the default codec.

The state is readable by anyone who can see the message, and a client can forge it. Never keep secrets in durable fields, and never base an authorization decision on one alone.

Attributes:

  • codec (Codec) –

    How the state is written into custom_ids. risa.codecs.BASE85 by default; BASE32768 and URO14 from the [radixly] extra carry more than twice as much.

InStore ¶

Bases: Struct

Keep a view's durable state in a store, under a key the message carries.

The components carry only a random key, and the state is one record in the client's store of the name store. It has no size bound, every process of a bot shares it through a distributed store, and it expires.

Attributes:

  • ttl (float | None) –

    Seconds an untouched record lives. Every click restarts the clock, so only abandoned views expire. None keeps records forever, including the ones a deleted message or a failed send leaves behind. There is no default, since no lifetime suits both a confirmation dialog and a role menu.

  • store (str) –

    Which of the client's stores holds the state: "default" for the client's store=, or a key of its stores=.

codec property ¶

codec

The codec the store key is written in, always base85.

DurableField ¶

Bases: Struct

One durable field of a view.

Attributes:

  • name (str) –

    The field's name.

  • annotation (object) –

    The field's type.

  • has_default (bool) –

    Whether the field has a default, which lets state written before it was added still be read.

StateSchema ¶

The durable fields of a view, in declaration order, and their packing.

risa builds one per view at registration. State is packed as the values of the durable fields in order, so appending a field that has a default leaves earlier state readable.

fields property ¶

fields

The durable fields, in declaration order.

durable property ¶

durable

Whether the view has any durable fields.

fingerprint property ¶

fingerprint

The hash of the durable fields' names and types, which state is tagged with.

empty_fingerprint property ¶

empty_fingerprint

The fingerprint of a view without durable fields.

    The schema of the class's durable fields.

Raises:

  • ViewDeclarationError –

    If a prop has no default, a risa.Prop marker sits inside an annotation instead of around it, or a field's type cannot be described.

accepts ¶

accepts(fingerprint)

values ¶

adopt(view, source)

pack(values)

Pack the values of the durable fields, in order, into state.

Returns:

  • bytes –

    The packed state, empty for a view without durable fields.

Raises:

  • StateEncodeError –

    If a value cannot be serialized.
